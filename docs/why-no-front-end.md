# Why the release desk has no front end

A release manager needs a clear record: the proposal, the tests, the reviewer and the outcome. A database holds those facts. Claude Code, Codex, OpenCode or Cursor runs the same commands to read and update them.

The base produces branded, read-only HTML snapshots for the week and for each change review. They are printable and shareable within your access policy. They are snapshots, not live screens.

A screen adds mobile access, authenticated review buttons, concurrent editing and visual script comparison. This base has none of those, and does not enforce separation of duties through signed-in identities. It records named decisions by trusted operators. Enterprise DNA can build the interface and identity controls your team needs into its version.

The rehearsal runner executes supplied fixtures in a disposable database. It never deploys to production. Your approved deployment process remains responsible for real changes, credentials, backups and recovery.
